# nuLiga-Fixtures

Gekürzte, **anonymisierte** Nachbildungen echter nuLiga-Seiten (HHV, Verein
TSF Heuchelheim, Club-ID 69723, Saison 2026/27) — gleiche Tabellen-/Link-
Struktur wie das Original, aber:

- Namen von Mannschaftsverantwortlichen und Schiedsrichtern sind durch
  eindeutig erfundene Platzhalter ("Mustermann, Max") ersetzt,
- iCal-/Kalender-Tokens und Kontaktdaten sind entfernt.

Die Platzhalternamen dienen den Datenschutz-Tests: sie dürfen in keinem
Parser-Ergebnis auftauchen. Echte nuLiga-Seiten NICHT ungekürzt hier ablegen.
