# sport.de-Fixtures

Aus der **Beschreibung** der öffentlichen sport.de-Seiten NACHGEBAUT, nicht von der echten Seite: Die Parser sind gegen die echte Struktur
NICHT verifiziert. Sobald echtes HTML vorliegt (siehe `/system/sportde`, Diagnose), Fixtures ersetzen/ergänzen. Es stehen nur Vereins-/Spielinformationen
und Platzhalter-Namen für Spieler ("Beispielspieler") darin; sie dürfen nirgends persistiert werden (Test in `sportde.test.ts`).
