# HBL-Fixtures

Aus der **Beschreibung** der öffentlichen HBL-Seiten (opel-hbl.de) NACHGEBAUT, nicht von der echten Seite: Die Parser sind gegen die
echte Struktur NICHT verifiziert. Sobald echtes HTML vorliegt (siehe `/system/hbl`, Diagnose), Fixtures ersetzen/ergänzen.
Es stehen nur öffentliche Vereins-/Spielinformationen darin, keine Personen.
